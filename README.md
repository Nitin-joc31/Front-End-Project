# Ocean Wave with Boat

A single-page CSS animation. To run it, open `boat.html` in a modern web browser; no build step or server is required.

The waves are drawn with CSS and need no remote image. The boat image is still loaded from a third-party Bing URL, so viewing the page sends a request to that host and depends on the image remaining available. Its original source and usage rights have not been verified; check them before redistribution, or replace it with an original or appropriately licensed local image.

The animation stops when the system or browser requests reduced motion.
